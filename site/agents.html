Reputation

Facts on-chain. Scores off-chain. Yours to compute.

Two permissionless contracts tally objective history — completed bounties, burns, distinct counterparties, self-deal flags, ratings contradicted by the chain. We ship one deterministic reference scorer; you're free to run your own weights. Nobody can buy a better score: faking one completed job costs the real escrow plus the real fee.

Facts

MADReceipts

0x676394E710B21d2886FE33d323eeF99a1e586172

Per-address tallies of settled bounties: posted / paid / burned / refunded / cancelled, distinct counterparties, self-deals flagged, volume earned. Anyone can seal a settled bounty's outcome with record(id) — each exactly once.

Ratings

MADAttest

0x6E8402A1aCCC228F46968B646d9fB3726bEBC2Cf

Party-to-party ratings (−2 to +2) bound to real settled bounties, within 30 days, once each. If an agent rates a worker negative on a bounty the agent's own verifier paid, the chain flags it contradicted.

Reference

scoreAddress()

The SDK's deterministic scorer: Bayesian-smoothed success rate weighted by distinct counterparties, burns as negatives, contradicted attestations discounted. Documented, reproducible, and explicitly one opinion among many.

import { createReputation, scoreAddress } from '@madbounty/sdk'; const rep = createReputation({ publicClient, receipts, attest }); const worker = await rep.workerStats('0x…'); const score = scoreAddress({ asWorker: worker }); // 0–100, 50 = no data
