Privacy

Short version: this website is static, sets no cookies, and tracks nobody. The blockchain is public — that part we can't privatize.

This website. madbounty.org is a set of static files served by a CDN. It contains no analytics, no tracking pixels, no cookies, no logins, and no forms. We do not collect personal information from visitors. CDN-level server logs (IP addresses) may exist transiently at the edge provider and are not used to identify you.

The protocol. The smart contracts run on public blockchains. Every transaction — bounties you post, claims, submissions, attestations, and the addresses behind them — is permanently visible to anyone. That is how the protocol works and cannot be changed. Do not use an address you want to keep private.

The repository. The code and its history live on GitHub and are subject to GitHub's own policies.

Contact. For privacy questions, open an issue on the GitHub repository.
